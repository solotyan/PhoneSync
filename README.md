# PhoneSync

Программа для беспроводной синхронизации музыкальных файлов с телефона на ПК по протоколу FTP.

## Возможности

- Подключение к телефону по Wi-Fi (без USB-кабеля)
- Автоматическое скачивание новых файлов
- Пропуск уже существующих файлов
- Настройка через файл config.json

## Установка

1. Скачайте архив из раздела [Releases](../../releases)
2. Распакуйте в любую папку
3. Установите FTP-сервер на телефон (например, WiFi FTP Server из Play Store)
4. Запустите FTP-сервер на телефоне и запомните IP-адрес
5. Отредактируйте файл `config.json` — укажите IP телефона
6. Запустите `PhoneSync.exe`

## Конфигурация

Файл `config.json`:
```json
{
  "PhoneIp": "192.168.1.100",
  "PhonePort": 2121,
  "FtpUser": "anonymous",
  "FtpPassword": "",
  "RemoteFolder": "/sdcard/Music/",
  "LocalFolder": "C:\\Music"
}
```
## Технологии
- C# .NET 8

- Git + GitHub
