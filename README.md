# PhoneSync

Программа для беспроводной синхронизации музыкальных файлов с телефона на ПК по протоколу FTP.

## Возможности

- Подключение к телефону по Wi-Fi 
- Автоматическое скачивание новых файлов
- Возможность выбора: пропускать одноименные файлы или нет
- Настройка файла конфигурации прямо в программе
- Возможность выбора расширений файлов для загрузки

## Установка

1. Скачайте архив из раздела [Releases](../../releases)
2. Распакуйте в любую папку
3. Установите FTP-сервер на телефон 
4. Запустите FTP-сервер на телефоне и запомните IP-адрес
5. Запустите `PhoneSync.exe`
6. Отредактируйте файл конфигурации согласно данным вашего FTP-сервера

## Конфигурация

Файл `config.json`:
```json
{
  "PhoneIp": "192.168.1.100",
  "PhonePort": 2121,
  "FtpUser": "anonymous",
  "FtpPassword": "",
  "RemoteFolder": "/sdcard/Music/",
  "LocalFolder": "C:\\Music"
}
```
